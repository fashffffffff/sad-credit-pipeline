# Data dictionary — applications.csv · кейс 2 · команда SAD!

14 колонок. Проверки формата — `credit_core/validation.py`; в API ошибка формата → HTTP 422 с кодом из колонки «Код ошибки», в пакетном режиме (CSV) → решение `NEED_MORE_DATA` с тем же кодом.

|Поле|Тип|Обяз.|Ограничение|Пример|Код ошибки|Комментарий (зачем поле)|
|-|-|-|-|-|-|-|
|app_id|string|да (сервер)|`app_NNNN`|app_0001|—|Номер заявки, генерируется сервисом. По нему клиент и сотрудники находят заявку, к нему привязан аудит.|
|age|integer|да|18–70 лет включительно|32|`MISSING_AGE`, `INVALID_AGE`; вне 18–70 → `AGE_OUT_OF_RANGE` (отказ, правило 1)|Нужен для правила 1 и баллов (до 20). Приложение клиента спрашивает дату рождения, но на сервер отправляет **только возраст** — дату рождения банк не хранит.|
|income|number|да|> 0, ₽ в месяц|120000|`MISSING_INCOME` (пусто → NEED_MORE_DATA), `INVALID_INCOME`; < 30 000 → `LOW_INCOME`|Главный показатель платёжеспособности: баллы (до 30), DTI, лимит суммы.|
|employment|enum|да|`employed`, `self-employed`, `student`, `retired`, `unemployed`|employed|`MISSING_EMPLOYMENT`, `INVALID_EMPLOYMENT` (значение не из справочника; `unemployed` → отказ, правило 2)|Стабильность дохода: баллы (до 25) и правило 2.|
|family|enum|да|`single`, `married`, `children`|married|`MISSING_FAMILY`, `INVALID_FAMILY`|Запас прочности семьи: баллы (до 15). Не наказываем за детей (см. 02_правила).|
|amount|number|да|10 000 – 5 000 000 ₽ и в границах продукта|500000|`MISSING_AMOUNT`, `INVALID_AMOUNT`; > 10 × income → `AMOUNT_LIMIT`|Сумма кредита: платёж, DTI, правило 8.|
|term|integer|да|3–60 месяцев и в границах продукта|24|`MISSING_TERM`, `INVALID_TERM`|Срок кредита: платёж и DTI.|
|decision|enum|да (сервер)|`APPROVED`, `REFUSED`, `NEED_MORE_DATA`, `MANUAL_REVIEW`|APPROVED|—|Итог конвейера. Ставит только сервис, клиент передать не может.|
|reason|string|да, если decision ≠ APPROVED|код из `08_reasons.md`, UPPER_SNAKE_CASE; пусто при APPROVED|HIGH_DTI|—|Объяснимость: каждое решение содержит причину. Клиент видит человеческий текст, а не код.|
|client_id|string|да (сервер)|`cli_NNNN`|cli_0001|`INVALID_CLIENT_ID`|Кто подал заявку. По нему клиент видит только свои заявки (RBAC), по нему же СМЭВ проверяет соответствие паспорта.|
|passport_hash|string|да|ровно 16 символов `[a-f0-9]`|f727a849055f2224|`INVALID_PASSPORT_HASH`|Отпечаток паспорта вместо самого паспорта. **Оригинал не хранится и даже не передаётся на сервер.** Считается в браузере клиента: OPRF (RFC 9497) → SHA-256 → первые 16 hex-символов. Простой SHA-256 номера небезопасен (номеров всего ~10¹⁰, хэш перебирается за минуты), поэтому к номеру примешивается секретный ключ сервера — но сервер при этом номера не видит. По отпечатку работают проверка дублей, СМЭВ, БКИ и антифрод.|
|dti|number|да (сервер)|≥ 0, 2 знака после запятой; порог 0,5|0.21|— (> 0,5 → `HIGH_DTI`)|Долговая нагрузка = аннуитетный платёж / доход. Формула: `payment = amount × r / (1 − (1 + r)^(−term))`, `r = 0,18 / 12` — ставка для DTI фиксирована (раздел 4 правил организаторов) для любого продукта. Проверено: совпадает с CSV во всех 99 заполненных строках.|
|bki_score|integer|да (от БКИ)|300–850; **< 550 = отказ** `BKI_DELINQUENCY`; < 500 считаем просрочкой|720|— (`EXTERNAL_TIMEOUT`, если БКИ не ответило)|Кредитная история: баллы (от −20 до +10) и правило 7. Получаем от БКИ по `passport_hash`.|
|smev_status|enum|да (от СМЭВ)|`MATCH`, `MISMATCH`, `TIMEOUT`, `NOT_CALLED`|MATCH|— (`MISMATCH` → `SMEV_MISMATCH`, `TIMEOUT` → `EXTERNAL_TIMEOUT`)|Подтвердило ли государство, что паспорт принадлежит клиенту. `NOT_CALLED` — СМЭВ не вызывали, потому что отказ стал ясен по анкете раньше (экономия запросов).|

**Поле, которого нет в CSV, но есть в сервисе:** `product_id` (enum из `products.csv`, по умолчанию `prod_standard`; не подходит под границы продукта → `PRODUCT_MISMATCH` со списком подходящих продуктов). В CSV продукта нет, поэтому для всех строк используем стандарт со ставкой 18% — как в формуле DTI организаторов.

**Чего нет и не будет:** ФИО, адрес, пол, национальность, номер паспорта, дата рождения — не собираются (минимизация ПДн и запрет дискриминации).
