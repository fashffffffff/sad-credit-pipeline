# Журнал использования ИИ

Команда SAD! ИИ (Claude Code) использовали как помощника: он писал код и черновики документов по нашим решениям и ТЗ.
Ключевые решения — выбор кейса, стека, данных, архитектурных принципов, дизайна — принимала команда. Каждый результат проверяли сами: запуском, тестами и ручным прохождением системы.
