# Как подключить вход клиента: Telegram, Яндекс ID, VK ID, звонок

Итого по деньгам: **0 ₽**. Все четыре способа бесплатные.

Ключи никому не отправляй и в чат не вставляй. Только в файл `.env` в корне проекта на маке и в `C:\credit\credit.env` на ноутбуке. Оба файла не попадают в git.

Адреса, которые будут спрашивать сервисы:

| Где | Адрес сайта | Адрес возврата после входа (callback) |
|-|-|-|
| Прод | `https://credit.fashf.ru` | `https://credit.fashf.ru/auth/callback/<сервис>` |
| Мак | `http://localhost:5173` | `http://localhost:5173/auth/callback/<сервис>` |

Вместо `<сервис>` подставь `yandex` или `vk`.

---

## 1. Telegram-бот — 0 ₽, ~5 минут

Как будет работать: клиент вводит номер на сайте и нажимает «Подтвердить в Telegram». Открывается наш бот, клиент жмёт «Поделиться номером». Бот сверяет номер, и сайт пускает клиента. Работает и с компьютера (Telegram Desktop), и с телефона.

1. В Telegram открой **@BotFather** → `/newbot`.
2. Имя бота: например `Фин-Тех · Кредит`. Username должен заканчиваться на `bot`, например `fintech_credit_sad_bot`.
3. BotFather пришлёт **токен** вида `123456789:AA...`.
4. `/setdescription` и `/setuserpic` (по желанию): описание и аватарка, можно взять `frontend/public/favicon-32.png`.
5. `/setdomain` → выбери бота → `credit.fashf.ru`. Это для кнопки «Войти через Telegram» на сайте (виджет работает только на настоящем домене, на localhost — нет; подтверждение номера через бота работает везде).
6. В `.env`:
   ```
   TELEGRAM_BOT_TOKEN=<токен>
   TELEGRAM_BOT_USERNAME=<username без @>
   ```

Почему не Telegram Gateway (коды как SMS): $0.01 за код, но пополнять можно только криптовалютой TON через Fragment, минимум ~$100. Бот делает то же бесплатно.

## 2. Яндекс ID — 0 ₽, ~10 минут

1. Зайди на https://oauth.yandex.ru/ под Яндекс-аккаунтом, который не удалишь (лучше командный или свой основной).
2. **Создать приложение** → тип **«Для авторизации пользователей»** (поменять потом нельзя!).
3. Название: `Фин-Тех · Кредит (команда SAD!)`, иконка до 1 МБ, контактная почта.
4. Платформа **«Веб-сервисы»** → Redirect URI, добавь оба:
   - `https://credit.fashf.ru/auth/callback/yandex`
   - `http://localhost:5173/auth/callback/yandex`
5. Доступы к данным: **«Номер телефона»** и **«Логин, имя и фамилия, пол»** (пол мы не используем и не храним — это требование кейса про дискриминацию; галочка нужна только ради имени). Почту не бери.
6. **Всё верно** → на странице приложения будут **ClientID** и **Client secret**.
7. По желанию: пройти верификацию аккаунта — без неё Яндекс показывает пользователю предупреждение перед входом. Для демо не критично.
8. В `.env`:
   ```
   YANDEX_CLIENT_ID=<ClientID>
   YANDEX_CLIENT_SECRET=<Client secret>
   ```

## 3. VK ID — 0 ₽, ~15 минут (+ ожидание проверки)

1. Зайди на https://id.vk.ru/business/go → «Мои приложения» → **«Добавить приложение»**. VK может попросить подтвердить действие кодом из SMS.
2. С 2026 года VK просит **подтвердить бизнес-профиль**. ИП или самозанятость не нужны, достаточно заполнить анкету (по отзывам разработчиков; если VK потребует ИНН организации — пиши, решим без VK).
3. Платформа **Web**:
   - Базовый домен: `credit.fashf.ru`
   - Доверенный redirect URL: `https://credit.fashf.ru/auth/callback/vk`
4. Домен у приложения VK только один. Для мака создай **второе приложение**: базовый домен `localhost`, redirect `http://localhost/auth/callback/vk` (VK требует без порта — локально проверим через прод, не страшно).
5. Вкладка **«Доступы»** → включи **телефон** (появится после подтверждения профиля).
6. В `.env` (ID приложения со страницы приложения; секрет не нужен — VK ID работает по PKCE):
   ```
   VK_CLIENT_ID=<ID приложения для прода>
   VK_CLIENT_ID_LOCAL=<ID приложения для localhost>
   ```

## 4. Вход по звонку (SMS.RU callcheck) — 0 ₽, ~10 минут

Как будет работать: клиент вводит номер, сайт показывает «Позвоните на +7 XXX — звонок бесплатный и сбросится сам». SMS.RU видит звонок с номера клиента и подтверждает его. Это надёжнее SMS: подделать входящий номер у операторов РФ сложно.

1. Регистрация на https://sms.ru/ (нужен твой номер телефона).
2. В личном кабинете: **«Программистам» → API** — там **api_id**.
3. Пополнять баланс не нужно: проверка звонком бесплатна (по их странице). Если кабинет попросит минимальный баланс — напиши, сколько.
4. Платные SMS (8,4–8,5 ₽ за штуку + 2–3 тыс. ₽ в месяц за имя отправителя у каждого оператора) **не подключаем**.
5. В `.env`:
   ```
   SMSRU_API_ID=<api_id>
   ```

## 5. Что сделать после

1. Положи те же строки в `C:\credit\credit.env` на ноутбуке (можно попросить меня — я зайду по ssh и допишу, но сами ключи ты вводишь через файл, не через чат).
2. Напиши в чат «ключи на месте» — какие именно сервисы готовы. Пока ключей нет, вход работает в **демо-режиме**: код подтверждения показывается прямо на экране с пометкой «демо».
