# Данные кейса 2 (от организаторов)

| Файл | Что это |
|-|-|
| `applications.csv` | 100 заявок, 14 колонок — без изменений, как у организаторов |
| `products.csv` | 5 кредитных продуктов, 10 колонок |
| `products.original.xlsx` | исходный файл организаторов |

**Важно про `products.csv`.** Файл организаторов `products.csv` на самом деле Excel-книга (формат xlsx, архив ZIP),
у которой просто расширение `.csv`; каждая строка CSV лежит в одной ячейке столбца A.
Обычный CSV-парсер на нём падает или читает мусор. Мы извлекли строки из книги без изменений
и сохранили настоящий CSV (UTF-8), а оригинал оставили рядом как `products.original.xlsx`.
